# Sprint 3 Planning Meeting
**Date:** Nov 29, 2024
**Sprint Duration:** Nov 18 - Dec 1, 2024
**Project Name:** FitCoach
**Sprint Goal:** Implement access to previous workouts, visualization system for macro calculation, workout page customization, database implementation and user information storage, and provide users with pre-made workouts.

---

### Sprint Goals
The primary objectives for this sprint are:
1. Store workouts performed by users locally, alongside other user information.
2. Allow user page customization with different color schemes and the option to save changes.
3. Enable viewing of previous workouts performed.
4. Provide access to macros to be consumed through a chart system.
5. Implement a set of pre-made workouts for users to access and use.

### Acceptance Criteria
By the end of Sprint 3, we plan to implement a system that: 
- Allows users to sign in, with their information stored in a database for retrieval during future sessions.
- Collects users' information and creates an appropriate nutritional plan with calories and macros to help visualize a proper diet aligned with their goals.
- Provides access to preset workouts to help users get started if they do not have existing workout plans.
- Creates an environment that allows users to customize the app according to their color preferences.
