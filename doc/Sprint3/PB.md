1. As a user, I want the application I am using to remember my email so I won’t have to sign in every time.

2. As a user, I want to be able to reset my password if I forget which one I used.

3. As a user, I want to be able to customise my page with different colours so I enjoy the looks of the application.

4. As a user, I want to be able to create workout routines that I can access later on.

5. As a user, I want to get recommendations on whether I should go up the weight or repetitions for an exercise when I begin to get comfortable doing it.

6. As a user, I want to be able to record my calories and macronutrients the application has calculated for me personally to see how much I have eaten and how much I have left to eat.

7. As a user, I want to be able to have an appropriate workout that suits my long-term goals and starting level even as a beginner.

8. As a user, I want to be able to comfortably navigate the app with little experience.

9. As a user, I want to earn badges to stay motivated to exercise more frequently.

10. As a user, I want to be able to follow people on the app and see their progress on the app.
