1. As a user, I want to be able to customize my page with different colours so I can enjoy the looks of the application.

2. As a user, I want to have access to my workout routines later on when I want to access them again.

3. As a user, I want to be able to have access to preset workout routines without having to create my own.

4. As a user, I want to get recommendations on whether I should up the weight or repetitions for an exercise when I begin to get comfortable doing it.

5. As a user, I want to be able to record my calories and macronutrients the application has calculated for me personally to see how much I have eaten and how much I have left to eat.

6. As a user, I want to be able to see streaks forming on the calendar to stay motivated to exercise more frequently.
