### Release Goal
The primary objective of this release is to deliver a fully functional version of FitCoach that meets the core requirements specified in the backlog.

---

### Scope of the Release
The scope for this release includes the following key features and epics:

<ul>
    <li><strong>Epic 1</strong>: User login & account creation</li>
    <ul>
        <li>Feature 1.1: Implement user login and registration.</li>
        <ul>
            <li>User Story 1: Resetting Password</li>
            <li>User Story 2: Account Creation</li>
            <li>User Story 3: Use email and password for registration</li>
        </ul>
        <li>Feature 1.2: Creating the account with the provided registration information.</li>
        <ul>
            <li>User Story 4: Remember me Feature</li>
        </ul>
        <li>Feature 1.3: Allowing a remember me button that remembers the user, which simplifies the login step.</li>
        <ul>
            <li>User Story 4: Remember me Feature</li>
        </ul>
        <li>Feature 1.4: Allowing the user to enter their current weight and view previous ones.</li>
        <ul>
            <li>User Story 7: Record Weight, in pounds, kilograms, or stones</li>
        </ul>
    </ul>
</ul>
<br>
<ul>
    <li><strong>Epic 2</strong>: Customization</li>
    <ul>
        <li>Feature 2.1: Customize the look of the website through different themes.</li>
        <ul>
            <li>User Story 6: Customize page colors</li>
        </ul>
        <li>Feature 2.2: Allow the user to input workouts in.</li>
        <ul>
            <li>User Story 8: Create workout routines</li>
            <li>User Story 16: Workouts for long-term goals</li>
        </ul>
        <li>Feature 2.3: Allow the user to customize the workout view.</li>
        <ul>
            <li>User Story 9: Beginner plan available</li>
            <li>User Story 10: Recommendations to increase weight or reps</li>
        </ul>
    </ul>
</ul>
<br>
<ul>
    <li><strong>Epic 3</strong>: User Interface Enhancements</li>
    <ul>
        <li>Feature 3.1: Mobile-responsive design.</li>
        <li>Feature 3.2: Improved navigation and accessibility.</li>
        <ul>
            <li>User Story 17: Easy navigation with little experience</li>
        </ul>
    </ul>
</ul>
<br>
<ul>
    <li><strong>Epic 4</strong>: Calories</li>
    <ul>
        <li>Feature 4.1: Section for inputting calories and food eaten throughout the day.</li>
        <ul>
            <li>User Story 12: Track calories consumed</li>
        </ul>
        <li>Feature 4.2: Calorie calculation for the given weight, height, age, and gender.</li>
        <ul>
            <li>User Story 14: Appropriate macronutrient goals for protein, carbs, and fats</li>
        </ul>
        <li>Feature 4.3: Displays the number of calories allowed to eat for the rest of the day.</li>
        <ul>
            <li>User Story 13: Track macronutrients consumed vs. remaining</li>
        </ul>
    </ul>
</ul>
