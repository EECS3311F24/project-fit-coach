## Unfinished Tasks

During Sprint 2, we encountered one key task that remains incomplete, which we will carry forward into the next sprint. This task will be refined into a new user story for prioritization in Sprint 3.

1. **Exercise Recommendations for Progression**
   - **Story:** As a user, I want to receive recommendations on whether to increase the weight or repetitions for an exercise as I begin to get comfortable with it.
   - **Acceptance Criteria:** The app should detect when users achieve a certain level of ease with an exercise and provide a suggestion for progression, either by increasing the weight or the number of repetitions.

---

## Practices to Continue

1. **Regular Code Reviews:** Conducting code reviews allowed us to maintain quality standards and detect issues early. This practice has been beneficial, and we will continue it in the next sprint.
2. **Collaborative Planning Sessions:** Our team planning sessions helped align everyone on priorities and distribute tasks effectively. We plan to continue these sessions for each new sprint.

---

## New Practices to Consider

1. **Earlier Integration of Frontend and Backend Work:** We found that integrating frontend and backend features earlier in the sprint would allow for smoother development and reduce last-minute debugging.
2. **Documentation Updates Throughout the Sprint:** Updating documentation as we complete each feature will ensure everything is up-to-date by the end of the sprint, minimizing the need for catch-up documentation efforts.

---

## Practices to Avoid

1. **Last-Minute Feature Adjustments:** Making changes to features toward the end of the sprint caused some delays and confusion. In the future, we will aim to lock in feature specifications earlier to prevent this.

---

## Best/Worst Experiences During Sprint 2

- **Best Experience:** The highlight of Sprint 2 was successfully implementing the calorie and macronutrient tracking features, knowing that these provide valuable functionality for users focused on nutrition. Seeing this feature in action was rewarding and validated our efforts.
  
- **Most Challenging Experience:** Our biggest challenge was balancing the integration of multiple new features within a short timeframe. This made scheduling more difficult, but it also highlighted areas where we can improve coordination between teams.
