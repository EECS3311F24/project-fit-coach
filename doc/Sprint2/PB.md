2. As a user, I want to be able to reset my password if I forget which one I used.

3. As a user, I want to get an error message if I enter the incorrect login details.

4. As a user, I want to be able to customise my page with different colours so I enjoy the looks of the application.

5. As a user, I want to be able to use the appropriate system to record weight whether in pounds, kilograms or stones.

7. As a user, if I identify as a beginner I want to have a beginner plan to help me get started.

8. As a user, I want to get recommendations on whether I should go up the weight or repetitions for an exercise when I begin to get comfortable doing it.

9. As a user, I want to be able to record my calories to see how much I have eaten.

10. As a user, I want to know how much macronutrients I have consumed and how much I have left to eat.

11. As a user, I want to know what would be an appropriate amount of protein, carbs and fat for me to consume daily to suit my goals.

12. As a user, I want to be able to have an appropriate workout that suits long-term goals.

13. As a user, I want to be able to comfortably navigate the app with little experience.

14. As a user, I want to earn badges to stay motivated to exercise more frequently.
